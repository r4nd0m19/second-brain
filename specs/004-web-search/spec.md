# Feature Specification: 联网检索（库外兜底）

**Feature Branch**: `004-web-search`

**Created**: 2026-10-02

**Status**: Draft

**Input**: User description: "联网检索能力（F4 候选）：当第二大脑的本地库无相关内容、且问题需要外部或实时信息时，问答可以联网搜索并基于搜索结果作答，回答中给出网页来源链接。已定约束：博查 Bocha 供应商、key 未配置时静默降级、受控工具循环（本地优先联网兜底）、来源区分展示、结果不入库、外部内容按不可信处理、成本可控、可复用给 MCP。"

## 背景与问题 *(mandatory)*

现状：问答只在本地库（资料/浏览记录/对话/笔记）内检索；命中失败时模型凭**自身训练知识**作答——对训练截止后的行情、外部资源、他人主页等"库外且需要实时/外部信息"的问题，只能给出"我无法联网"或过时信息。

真实触发（2026-10-02）：用户要求"找与我方向相似、接单多的 Upwork 自由职业者主页"——本地库没有这类信息（那是别人的主页），模型也无联网入口，回答只能拒绝。

本 feature 在**库外兜底路径**上增加联网检索：本地库无相关内容时，问答可搜索网页、基于搜索结果作答，并附可点击的网页来源。本地命中路径不变（本地优先）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 库外问题联网作答 (Priority: P1)

用户问一个本地库没有、但网络上有的问题（如"找一下和我方向相似的 Upwork 自由职业者"），系统联网搜索并以搜索结果为依据作答，回答中列出网页来源（标题+链接，点击新标签打开原文）。

**Why this priority**: 这是本 feature 的全部核心价值——把"无法回答"变成"联网回答"。

**Independent Test**: 提一个本地库必然没有的实时性问题，验证回答基于网页内容且来源链接可点、可达。

**Acceptance Scenarios**:

1. **Given** 本地库无相关内容且问题需要外部信息，**When** 提问，**Then** 回答引用至少 1 条网页来源，来源含标题与可点击链接（新标签打开原文）
2. **Given** 本地库有强相关内容，**When** 提问，**Then** 回答仍以本地资料为依据、出处为本地来源（不触发联网）
3. **Given** 搜索返回空结果**或结果与问题不相关**，**When** 提问，**Then** 明确告知未搜到相关内容 / 结果不相关，不编造；措辞不得暗示"尚未联网"
4. **Given** 搜索结果含噪音（部分条目不相关），**When** 提问，**Then** 相关条目按相关度排在引用前列、明显不相关条目不出现在引用中（FR-012 重排过滤）

---

### User Story 2 - 联网来源与本地来源的区分与降级 (Priority: P2)

用户能一眼分辨回答的依据来自"你的资料"还是"网络"；联网服务不可用（未配 key / 断网 / 服务故障）时，问答保持原有行为，不报错、不中断。

**Why this priority**: 可信度与稳定性底线——联网是增强，不能成为故障点。

**Independent Test**: 断开搜索服务凭据与网络，验证问答仍正常返回（模型知识作答），且回答照常可用。

**Acceptance Scenarios**:

1. **Given** 回答同时使用了本地资料与联网结果，**When** 查看出处区，**Then** 两类来源以不同标注区分展示，网页来源链接可点
2. **Given** 搜索服务不可用（凭据缺失/超时/故障），**When** 提问，**Then** 回答正常返回（退回模型知识），无错误提示、无流程中断
3. **Given** 联网结果被使用，**When** 回答结束，**Then** 搜索结果未写入本地库（资料列表与检索无新增数据）

---

### User Story 3 - 能力可复用（MCP 等入口） (Priority: P3)

联网检索实现为独立可复用能力，除对话端外可被 MCP 工具（Claude Code 等 harness）调用（接入可后置）。

**Why this priority**: 接口化避免二套实现；不是本 feature 的验收核心。

**Independent Test**: 对话端使用与 MCP 暴露共用同一检索组件接口。

**Acceptance Scenarios**:

1. **Given** 联网检索组件已实现，**When** 其他入口（如 MCP 工具）需要联网搜索，**Then** 可复用同一组件接口而无需重写（接入另列任务）

---

### Edge Cases

- **模型"跳过工具"倾向**（调研已知：模型对自认为知道的问题不调用搜索工具）：系统提示与触发规则必须明示；验收包含"应触发但模型倾向不触发"的样例（如名人近况类问题）
- **搜索服务超时/故障**：在超时阈值内未返回则放弃联网、静默降级，不得拖垮回答
- **外部内容含恶意指令（提示词注入）**：联网内容按不可信输入处理，其内嵌指令不得影响系统行为
- **本地弱相关内容**（"库中可能相关"级别）：允许联网补充，且最终回答须说明依据来自网络而非本地
- **时间类问题**（"最近看过什么"）：本地时间清单路径优先；仅在本地明确无结果时才走联网
- **裸联网指令**（"发起联网搜索"，不含可检索内容）：不触发搜索，由回答自然引导用户给出具体问题（FR-011）
- **隐私边界**：搜索请求不得拼接用户本地库的隐私内容（浏览记录原文、笔记原文等）；
- **成本异常**：搜索结果条数与正文长度受上限约束，超出截断

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 问答在本地库无相关内容、且问题需要外部或时效性信息时，进行联网搜索并基于搜索结果作答
- **FR-002**: 联网作答的回答必须包含可点击的网页来源（标题 + 链接；原文在新标签打开）（2026-10-03 补记：回答内 [N] 角标点击改为弹「引文小窗」——标题/域名/原文摘录（`quote`）+「↗ 打开原文」按需新标签；出处列表「↗ 打开网页」维持直开——见 001 R41/T087）
- **FR-003**: 本地库命中（强相关）时不得以联网结果替代本地出处；联网仅在库外（含弱相关兜底）路径启用（**用户显式要求联网时除外**——见 FR-011）
- **FR-004**: 联网能力需凭据启用；凭据未配置或服务不可用时，系统静默保持现有行为（模型知识作答），不报错、不中断回答（2026-10-03 补记：**降级本身不变（不中断、不弹错）**，但"未能检索"的事实与**原因**对用户**可见**——联网被规划却未取得任何结果（供应商失败/额度用尽）时，回答来源行附「联网检索失败：{原因}，未使用网络来源」提示（meta 增 `web_failed` + `web_error` 原因码：余额不足/限流/额度用尽/服务不可用）；同时向模型注入"检索未成功"的系统说明，**禁止把失败编造成"已检索但内容不相关"或虚构结果描述**——用户实测两轮事故驱动，实施见 001 T083 及追记；**2026-10-04 再补记**：原因码增 **`no_results`**（搜索调用全部成功但零结果——与"服务故障"区分，文案「联网检索未找到相关结果，未使用网络来源」不套用"失败"模板）——用户实测：真实故障为"查询本身搜到 0 条"却被标"服务不可用"，见 001 T090）
- **FR-005**: 联网搜索结果仅用于当次回答，不写入本地库、不进入备份、不出现在资料列表中
- **FR-006**: 外部网页内容按不可信输入处理（防提示词注入）；搜索请求不得拼接用户本地库的隐私内容
- **FR-007**: 搜索结果条数与单条正文长度上限可配置（成本控制）
- **FR-008**: 联网来源与本地出处以不同标注区分展示（"来自你的资料" vs "来自网络"），引用编号统一可点
- **FR-009**: 联网检索以独立可复用组件实现（对话端消费；MCP 等入口复用同一接口，接入可后置任务）
- **FR-010**: 搜索服务商以可替换接口封装（更换供应商不改业务逻辑）；本次对接已选定的国产搜索服务
- **FR-012**（2026-10-03 增补）: **搜索结果质量保障**——搜索结果在注入回答前经**相关性复评**（复用检索重排器，对标题+摘要按用户问题打分）：低于下限的条目剔除、其余按相关度排序截取；全部低相关时换备用引擎重试一次（计入每日护栏），仍无可如实按"已检索但不相关"处理；重排不可用时保持原序（静默降级）；引擎档位、备用引擎与相关度下限均可配置——默认引擎以实测质量为准（sogou）（2026-10-03 补记：本段语境为智谱期设计——默认源已历经 SearXNG（R39）与 DeepSeek 服务端搜索（R40）两轮演进，"备用引擎重试"现仅存于智谱客户端内部（fallback_engine）；低相关重试的通用机制为 FR-014 免费加深变体与付费兜底开关）
- **FR-014**（2026-10-03 增补）: **搜索源自托管**——联网检索默认使用**自托管元搜索**（SearXNG：零成本、引擎集可配置），付费搜索 API 保留为可切换后端；**质量补偿（免费加深）**：结果相关度低于可配闸门时，自动改写查询变体二轮检索并合并（时间换质量）；免费源不计每日护栏与费用；付费兜底仅在显式开启时触发（**2026-10-03 再补记**：新增可切换源 **deepseek**——DeepSeek 官方 API 的服务端 web_search 工具（Anthropic 兼容端点），token 计费、无按次费，复用已付费的 DeepSeek 账户（零新账号）；**2026-10-03 用户确认默认源切至 deepseek**（searxng 保留可切换）；探针、同题对比评测与真机验收见 001 R40/T086）
- **FR-013**（2026-10-03 增补）: **多查询执行与读页**——规划器给出的**全部**联网查询都执行（各自计费与每日护栏配额）、结果按 URL 合并去重后统一复评；对复评后的前若干条结果**抓取原页正文**（并行、超时/字节/页数上限可控），以 **trafilatura 正文提取 + 段落级相关性筛选**（只注入与问题最相关的段落）替代纯摘要；任一环节失败（超时/反爬/非 HTML/提取空）回退该条的搜索摘要；读页整体可关闭（退回纯摘要流）；引用摘录来自页面正文——不做整站爬取、不绕过反爬、不落盘（2026-10-04 补记：**聊天内链接直读**——用户消息中的 http(s) 链接（每条消息至多 3 条；行内代码/代码块内的链接除外——那是"被讨论的数据"而非"指向"）由系统**确定性直读正文**作为 web 来源注入：复用读页管线及其全部防护（SSRF 预检/逐跳重定向校验/流式字节上限/总时限），编号先于搜索结果、不占每日护栏（零成本）、不经规划器；抓取失败 → 如实告知、**严禁按链接地址猜测内容**；规划器被明确要求**不再为链接本身发起 web_search**——见 001 T097 / R49）
- **FR-011**（2026-10-02 增补）: 用户显式要求联网搜索时（如「联网搜一下 X」「帮我查 X」）**优先联网**——即使本地有强相关命中也执行搜索，本地资料可一并作补充（引用编号本地在前、网络续接）；指令中没有可检索内容时（如「发起联网搜索」）不搜索、引导用户给出具体问题或关键词；用户问及联网能力（「能不能 / 怎么才能让你联网搜索」）时直接给出可用指令示例并说明可以做到；不得承诺"稍后去搜"（需要用户补充信息确定检索词时，可同时给出可直接发送的示例指令）；**任何情况下**不得向用户暴露系统内部机制（如 web_results、注入、工具调用入口等），也不得声称自己无法联网（2026-10-03 补记：**已联网但结果与问题无关时**，如实说明"已检索，但找到的内容与问题不相关 / 缺少所需数据"，通用知识部分明确标注来自通用知识；**不得说"我还没联网""你发联网指令我才能查"这类与事实不符的话**；换关键词重搜的表述为"我可以换关键词再搜一次（如『…』）"——用户实测事故驱动，实施见 001 T080；**2026-10-03 再补记**：时效诉求（"目前/最新"）的联网查询使用**当前年份**（规划器携带当前日期，不凭记忆猜年份）；回答模型同样携带当前日期以判断检索结果时效——见 001 T084）

### Key Entities

- **搜索结果条目**（临时）：标题、链接、摘要/正文片段、来源站点；仅存在于当次回答过程，不持久化
- **联网来源引用**：与本地出处并列的可点击来源（含外部链接标识），区别于本地资料的出处结构

## Non-Goals（本次不做什么） *(mandatory)*

- **整站爬取/爬虫**：不做站点遍历与批量抓取；仅对单次检索的前若干条结果做**受控单页读取**（FR-013：页数/大小/超时上限，失败回退摘要，不绕反爬、不落盘）
- **深度研究 agent**（多轮自主调研、多源交叉验证）：单次受控搜索，循环次数有界
- **无凭据时的备援搜索源切换**：只留可替换接口，不预置多供应商自动切换
- **联网结果入库**：临时使用，不入库、不参与本地检索排名
- **每轮自动联网**：只在库外兜底路径触发，不做默认叠加
- **联网内容的快照保存**（回到本地引用体系）：不在本次范围

## Non-Functional Requirements *(include if applicable)*

### Performance
- 联网兜底路径的搜索调用设超时阈值（默认 5s 级可配置）；超时即放弃联网、降级作答（2026-10-03 补记：默认值随源——SearXNG 10s / DeepSeek 服务端搜索 30s，见 R39/R40）
- 联网搜索对回答首字时间的增加在超时阈值以内（不因联网卡死流式输出）（补记：DeepSeek 源单查询含模型轮次实测 3.1–3.6s，联网轮总时延 12–18s；用户明确接受该时延换取索引质量）

### Reliability
- 搜索失败（超时/故障/空结果）必须降级为原有作答路径，问答整体成功率不受联网影响
- 未配置凭据时系统行为与现状完全一致（零感知）

### Security
- 外部内容按不可信输入注入模型（包裹标记 + 系统提示声明）；搜索结果中的指令一律不执行
- 搜索请求只含用户当前问题的改写关键词，不含本地库隐私内容

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 抽取 5 个"库外且需要外部信息"的问题，≥4 个回答包含可点击的网页来源且链接可达
- **SC-002**: 抽取 5 个"本地库有强相关内容"的问题，本地出处保持 100%（零回归、零误触发联网）
- **SC-003**: 搜索服务故障演练（去除凭据/断网）下，全部提问仍正常返回回答（降级成功率 100%）
- **SC-004**: 未配置凭据时，对既有问答行为零影响（抽样对比一致）
- **SC-005**: 联网兜底路径的回答首字时间在既有目标内（不劣于当前流式体验阈值）（2026-10-03 补记：源演进后联网轮总时延实测 12–18s——口径见 NFR Performance 补记；以时延换质量为用户选定）

## Assumptions

- 用户在搜索服务商注册个人凭据（免费额度）并配置到系统中；未配置时能力静默不可用
- 单用户自用；外部搜索的合规与配额由所选服务承担
- 与现有来源体系（引用编号/出处列表/时间范围回显）兼容，实现阶段细化统一编号方案
- 搜索服务商已选定（国产、国内直连、按次计费约 1 分/次档位，用户 2026-10-02 决策：成本优先），以可替换接口封装（2026-10-03 补记：源已经三轮演进——智谱按次 → SearXNG 自建零成本（R39/T085）→ 默认 DeepSeek 官方服务端搜索（token 计费、复用 LLM 凭据、无按次费，R40/T086）；"凭据未配置"的语境随之为 LLM key 缺省）
