# 快速验证指南：联网检索（库外兜底）

> 前置：检索与问答基线可运行（见 001 quickstart）；本功能验收不依赖自动化测试先行。

## 0. 前置准备

1. 在智谱开放平台（bigmodel.cn）注册、充值并获取 API Key
2. `server/.env` 增加：
   ```
   WEB_SEARCH_API_KEY=<智谱 API Key>
   # 可选：WEB_SEARCH_ENGINE=search_std（默认，￥0.01/次）/
   #        search_pro(￥0.03) / search_pro_sogou(￥0.05) / search_pro_quark(￥0.05)
   #        WEB_SEARCH_FALLBACK_ENGINE=search_pro_sogou（零链接兜底，默认开）
   #        WEB_SEARCH_MAX_RESULTS=5 / WEB_SEARCH_SNIPPET_MAX=800 / WEB_SEARCH_TIMEOUT_S=5
   ```
3. 重启服务：`cd server && .venv/bin/uvicorn app.main:app --port 8000 --host 0.0.0.0`

## 1. 库外问题联网作答（SC-001）

- 提问一个本地库必然没有、且需要外部信息的问题（示例："现在还有没有类似 Karpathy 那样做 AI 教学的博主，给我主页链接"）
- **预期**：回答基于搜索结果；出处区出现网页条目（标题 + 链接），链接**新标签打开**原文；来源标注"来自网络"
- 重复 5 个不同库外问题 → ≥4 个含可点击且可达的网页来源

## 2. 本地命中不联网（SC-002）

- 提问库内已知内容（如"SDD 的核心循环是什么"）
- **预期**：出处全部为本地资料（无 web 来源、无"来自网络"标注）——本地优先零回归

## 3. 降级演练（SC-003 / SC-004）

- **去凭据**：注释 `WEB_SEARCH_API_KEY` 重启 → 任意提问 → 行为与现状完全一致（库外问题退回模型知识作答，无报错延迟）
- **超时故障**：把 `WEB_SEARCH_TIMEOUT_S=0.001` 重启 → 库外提问 → 回答正常返回（联网放弃，日志可见降级）
- **空结果**：提问极端生僻词 → 若搜索无结果，回答如实说明未搜到，不编造

## 4. 安全抽查（FR-006 / R4）

- 外部内容注入：找一个页面含"忽略以上指令"类文本的被引网页（或本地构造 mock）→ 回答不受其指令影响
- 隐私：核对日志/抓包——搜索请求仅含改写后的检索词、**不含本地库内容**；追问场景的检索词可包含必要的对话上下文（指代消解产物，R3 补记 2026-10-03）

## 6. 显式联网指令（2026-10-02 增补，FR-011）

- **裸指令**：发「发起联网搜索」→ **预期**：不触发搜索；回答自然请用户给出要搜索的问题/关键词（如「你想让我搜什么？把关键词发我即可」）；**不得**出现「web_results / 系统注入 / 工具入口」等内部机制措辞，也不得说"无法联网"
- **显式指令+内容**：发「联网搜一下今天北京天气」→ **预期**：直接联网作答（`web` + 网页来源）
- **显式指令 vs 本地强命中**：对库内已有内容发「联网搜索一下 X」→ **预期**：仍执行联网；`citations` 本地在前（1..N）、web 续接（N+1..），回答以网络为主、本地为补充
- **本地检索意图不误判**：「搜一下我的资料里的 X」→ 不触发联网（走常规检索）
- **能力类问句**：「怎么样才能让你联网搜索 / 去搜人」→ **预期**：直接说明可以做到并给出指令示例（可结合你的目标代拟一条）；不得出现机制措辞或"做不到"；不得承诺"我这就去搜/你确认后我就查"（需要补充时直接给出可发送的示例指令）
- **概念题不联网**：「用一句话解释什么是递归」类通用知识问题 → 不触发联网（2026-10-02 收紧：概念题随机联网违反 FR-001）
